## 功能

- [x] 基础定位功能
- [x] 骑行路线导航
- [ ] 个人帐号,可以存储常用地点和设置(已支持手表本地收藏）
- [x] 手机端推送起始地点和目的地,直接开始导航
- [x] 支持手机可用的情况下由手机提供定位能力, 以提升导航精准性并降低手表功耗
